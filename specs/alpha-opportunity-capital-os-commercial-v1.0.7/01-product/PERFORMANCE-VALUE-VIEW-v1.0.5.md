## Presentation rules

- Alpha, risk and time savings are separate sections.
- `AUTOMATION_VALUE_ONLY` may never be visually presented as Alpha.
- `RISK_CAPITAL_OS_VALUE` may never be described as outperforming the benchmark unless excess return independently proves that statement.
- `STOP_PRODUCT` must be plain-language and visible; do not hide it behind a neutral score.
- Until minimum evidence is satisfied, show `EVIDENCE_INSUFFICIENT` rather than an inferred verdict.

## Strategy attribution

Strategy attribution remains visible, but cross-exchange spread is labeled **Opportunistic / Dislocation**, not a core expected return source.
