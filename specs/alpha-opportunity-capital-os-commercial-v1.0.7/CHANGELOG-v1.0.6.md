# CHANGELOG — Commercial v1.0.6

## Personal UX & Action Experience Closure

v1.0.6 adds no strategy, venue, pricing model, Alpha claim, execution privilege or calculation semantic.

It freezes a simplified owner experience over the existing v1.0.5 core:

- primary navigation is limited to `Today / Opportunities / Positions / Portfolio / Performance`;
- advanced operational surfaces move under `Advanced / Settings`;
- Today presents no more than three primary capital actions;
- the user consumes deterministic action states: `EXECUTE / HOLD / ROTATE / EXIT / KEEP_CASH`;
- opportunity/action cards use progressive disclosure: `Action → Why → Calculation Details → Trace`;
- alerts are formalized for qualified opportunity, exit, risk and execution failure events;
- a lightweight Capital Inventory Plan exposes venue-level ready/excess/shortfall balances without enabling withdrawals;
- strategy/economic maturity is visible in user language and never hidden behind headline return;
- risk presentation prioritizes money-at-risk, stress loss, emergency exit cost and liquidation distance where applicable;
- Research-only Structured/Options modules are hidden from default navigation until enabled by owner preference and readiness;
- AI remains explanation-on-demand over canonical facts; it is not a primary decision surface.

All v1.0.1–v1.0.5 domain, calculation, execution, Alpha Proof and survival-gate contracts remain unchanged unless this changelog explicitly states a presentation-only supersession.
