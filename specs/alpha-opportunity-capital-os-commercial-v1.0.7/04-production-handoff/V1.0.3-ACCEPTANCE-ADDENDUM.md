# v1.0.3 Acceptance Addendum

Commercial V1 handoff additionally requires:

- module registry loads deterministically and disabled modules cannot emit executable/allocation-eligible opportunities;
- Today view can render one portfolio summary plus max three primary recommendations;
- unified feed merges Carry/Yield opportunities without requiring module browsing;
- Capital Rotation produces identical recommendations for identical inputs/config;
- no voluntary rotation occurs below both churn thresholds;
- emergency risk reduction bypasses churn guards but remains auditable;
- `KEEP_CASH` is possible when no eligible opportunity improves the portfolio;
- Action Plan is invalidated when source/target opportunity or portfolio evidence becomes stale;
- Structured/Options appear only as Research-only/Disabled until later packs;
- Alpha Proof still uses reconciled realized economics, not recommendation counts.
