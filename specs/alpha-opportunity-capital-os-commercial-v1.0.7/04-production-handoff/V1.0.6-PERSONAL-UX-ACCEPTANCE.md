# Commercial v1.0.6 Personal UX Acceptance

## Navigation / complexity

- [ ] Primary navigation contains only Today / Opportunities / Positions / Portfolio / Performance.
- [ ] Replay, Connections, Risk, Modules/readiness, Calculation Trace, AI/provider and diagnostics are secondary/advanced.
- [ ] Module pages are not required to discover or execute top owner actions.

## Today

- [ ] Today displays at most three primary actions.
- [ ] `HOLD` and `KEEP_CASH` are represented as valid deterministic outcomes.
- [ ] Each action shows capital amount, holding-period expected net result where applicable, monetary risk summary, evidence maturity and one primary CTA.
- [ ] An opportunity with high expected return but UNPROVEN maturity cannot visually suppress the maturity warning.

## Progressive disclosure

- [ ] Default action card does not expose formula IDs, internal risk score or raw registry state.
- [ ] `Why` uses deterministic reason codes.
- [ ] `Calculation Details` uses canonical analysis/calculation facts.
- [ ] `Trace` uses CalculationTrace and requires explicit drill-down.
- [ ] AI unavailable state does not remove action/reason/calculation usability.

## Alerts

- [ ] OPPORTUNITY_READY is emitted only for currently qualified/fresh/owner-eligible actions.
- [ ] EXIT_RECOMMENDED links to the current position/version and current exit reason.
- [ ] RISK_ACTION_REQUIRED is reserved for material owner-action risk.
- [ ] EXECUTION_FAILURE covers unresolved partial-fill/leg/reconciliation failures.
- [ ] Alert dedupe/expiry works and never bypasses pre-trade revalidation or confirmation.

## Capital Inventory

- [ ] Ready/reserved/excess/shortfall/blocked capital is calculated per venue/account.
- [ ] Locked/unavailable capital is not counted as ready.
- [ ] A funding shortfall can make an otherwise qualified opportunity `not currently executable` without changing opportunity truth.
- [ ] No V1 path initiates transfers or requires withdrawal permission.

## Convenience / user effort

- [ ] Owner can understand the next required action from Today without visiting a strategy/module page.
- [ ] Assisted execution is reachable from the action card in no more than one detail review + one explicit confirmation.
- [ ] Active position requiring exit/risk attention is visible on Today and Positions.
- [ ] Performance remains the final proof surface: realized net P&L, benchmark/excess return, drawdown and product value state.

## No scope regression

- [ ] No calculation, strategy threshold, risk formula, Alpha Proof rule or execution safety gate changed in v1.0.6.
- [ ] Structured/Options remain allocation/execution disabled unless separately promoted by future contracts.
