# Launch Gates

## Gate A — ENGINE_READY

- four public adapters healthy;
- formula goldens pass;
- 30-day replay reproducible;
- risk/capacity outputs complete;
- module registry and Capital Rotation golden/acceptance tests pass;
- disabled Structured/Options modules cannot enter allocation.

## Gate B — PAPER_PRODUCTION_READY

- 7 continuous days on live feeds;
- no unresolved accounting drift;
- opportunity decay tracked;
- simulated partial fills enabled.

## Gate C — ASSISTED_LIVE_READY

- secure trade credentials;
- private stream recovery;
- execution chaos suite passes;
- owner confirmation flow;
- kill switches verified.

## Gate D — AUTO_READY

- strategy version is AUTO_APPROVED;
- owner numeric policy saved;
- assisted track record exists;
- drawdown/loss limits configured;
- operator alerts verified.

## Gate E — PUBLIC_COMMERCIAL_READY (future)

Not part of V1 launch. Requires legal/regulatory review by target jurisdiction, identity/tenant isolation, consent, entitlement/billing, support and public-facing disclosures.


## Gate F — ECONOMIC_TRUTH_READY (v1.0.2)

This gate is mandatory before the product makes any personal-profitability claim. It requires AP0 instrumentation and an explicit economic state. Software may launch privately while state is `UNPROVEN`; it may not present projected/expected opportunity return as proven owner alpha.

`ALPHA_VALIDATED` and `EXPANSION_WORTHY` follow `04-production-handoff/ALPHA-PROOF-GATES.md` and are separate from technical production readiness.

## v1.0.6 Personal UX gate

Before PRIVATE owner launch, all items in `V1.0.6-PERSONAL-UX-ACCEPTANCE.md` must pass. Failure of convenience/clarity tests blocks owner launch UX but does not change underlying strategy economic status.
