# v1.0.5 Product Value Acceptance

v1.0.5 is accepted when:

- Product Value policy parses and is version-pinned;
- `ProductValueReport` validates against schema;
- Alpha facts are reused from Alpha Proof, not recalculated independently;
- synchronized max-drawdown comparison has deterministic tests;
- zero benchmark drawdown returns null relative reduction without error;
- workload measurements preserve source quality;
- insufficient evidence returns `EVIDENCE_INSUFFICIENT`;
- Alpha validated produces `ALPHA_PRODUCT_SUCCESS / CONTINUE`;
- risk-value fixture produces `RISK_CAPITAL_OS_VALUE / KEEP_REDUCED_SCOPE / DO_NOT_EXPAND`;
- automation-only fixture produces `AUTOMATION_VALUE_ONLY / KEEP_REDUCED_SCOPE / DO_NOT_EXPAND`;
- no-value >=120-day fixture can produce `NO_MATERIAL_VALUE / STOP_PRODUCT`;
- estimated workload data alone cannot trigger STOP;
- AI cannot override any product-value decision;
- Cross-Exchange Spread is surfaced as Opportunistic, without dedicated HFT infrastructure.

This gate does not certify profitability; it certifies correct product-value classification.
