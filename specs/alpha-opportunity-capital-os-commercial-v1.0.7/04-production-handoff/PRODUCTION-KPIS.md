# Production KPIs

## Economic truth

Primary KPIs:

- Realized Net P&L;
- Expected vs Realized Return Error;
- Max Drawdown;
- Loss Event Rate;
- Capital Utilization;
- Opportunity Precision;
- Execution Success Rate;
- Unhedged Exposure Time.

Secondary:

- detected opportunities;
- qualified opportunities;
- average capacity;
- opportunity decay time;
- fee/slippage model error.

Do not use “number of opportunities” or headline APR as a primary success KPI.

## Validation target, not performance promise

Commercial V1 should prove that the system can correctly identify, execute, account for and safely reject opportunities. A profitable live track record is desirable but is not a software acceptance criterion because market conditions vary.


## v1.0.2 owner economic value KPIs

The top-level owner dashboard must additionally show:
- benchmark TWR;
- excess return and annualized excess return when eligible;
- shadow benchmark ending NAV;
- attributable product run cost;
- economic value USD;
- value/run-cost ratio;
- economic evidence state;
- KEEP / DO_NOT_EXPAND / EXPANSION_WORTHY / STOP decision.

A profitable portfolio that underperforms the benchmark is not successful Alpha Proof.


## v1.0.3 portfolio KPIs

- voluntary turnover vs policy cap;
- rotation incremental benefit expected vs realized;
- capital utilization by module;
- time in cash and reason codes;
- recommendation expiry rate;
- action-plan execution/cancellation rate.
