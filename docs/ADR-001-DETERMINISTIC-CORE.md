# ADR 001 — 确定性核心与本地模拟隔离

状态：接受，限本地开发阶段。

用户请求按 v1.0.7 包开发产品。仓库最初为空，包是规格而非可运行应用。本实现采用 TypeScript 单服务 + React，领域公式与 UI 分离；AI 仅可解释既有事实。经济与成熟度状态保持未验证。

## 决策

1. 所有策略收益计算位于领域层，UI 读取保存的计算结果。导出只序列化当前已物化的决策快照，不触发策略计算。
2. 规范 Golden Fixtures 作为明确标识的合成场景，不能冒充历史或当前行情。
3. PAPER 实际行为只能改变本地模拟账本。服务端不支持真实模式或任何密钥提交。
4. 为交付可运行的本地工作流，本阶段使用原子替换的 JSON 状态存储，而非暗示 PostgreSQL 已集成。只允许单进程使用同一文件；真实交易上线前必须替换为事务仓储。
5. 开仓的来源、配置、场景哈希和所有者操作作为哈希链接的事件保存。哈希链用于检测偶发/局部修改，不抵御有文件写权限者重写整条链，也不声称具备外部不可变审计保证。
6. 公开盘口只做连接诊断，不会混入模拟机会；错误不会回退为伪造实时数据。
7. 分配与实盘提升是不同问题：规范公式通过测试不会提升策略，Structured/Options 不启用。

## 后果

无需账户、AI、数据库或网络即可体验核心本地操作。开发模型中的费用分配、规模曲线和风险参数都有显式假设，不能直接升级为实盘模型。迁移到生产存储、事件驱动执行和真实账户连接仍是后续工作，而非仅添加部署参数。
