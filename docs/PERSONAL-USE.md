# 个人使用版：行情、模拟、手动记账、持仓与绩效

本批范围是前四项个人用途。运行保障、备份、通知基础设施后置；不接真实订单，不需要交易所密钥。

## 开始使用

1. 在“机会”连接公开市场，默认 BTC / ETH。
2. 在“资金组合”选择“真实行情模拟”或“个人手动记账”，录入各交易所初始资金。两本账独立，初始均为零。
3. 模拟：打开公开候选详情，选择单腿参考规模，核对两腿需备资金、持有周期、模型净收益及限制；条件允许时点击“继续研究模拟”，确认规模及提醒阈值。
4. 手动：在“持仓”录入已经发生的成交，填写工具、方向、基础币数量、成交价格、报价币美元汇率、实际手续费；衍生品还需填写占用保证金。支持一腿或两腿。
5. 在“持仓”查看估值和提醒，模拟平仓或录入实际平仓；手动资金费及补录费用以交易所流水编号防重复。
6. “绩效”查看已实现价差、已入账资金费、费用、未实现损益、净值记录及流水。个人模式的唯一分析导出包含两本账及实际市场输入，不带旧版示例资金和示例机会。

初始资金按成交前总资金录入，避免把当前可用余额和已持仓本金混记。后续入金/出金属于外部资金流，不计收益。每次成交录入是一批数量；分批成交可分批建记录，平仓关闭该批全部剩余数量，暂不支持改单、部分减仓和历史成交编辑。

## 怎样阅读机会看板

首屏给出当前结论，组合数量不代表可交易机会。候选分为“值得观察”“暂不满足”“数据待更新”；缺失、过期或连接中断的数据不会作为有效机会。默认只看值得观察的候选，没有时可查看另外两组的原因。

卡片将单腿参考规模与两腿全额资金分开，净收益对应明确持有期，已扣模型成本与储备。默认按持有期排序；可选的年化对比使用两腿本金及入场费归一化，只是算术比较，不假设收益持续重复，现货价差不参与年化排序。

详情上方随行情更新，下方折叠区域保留打开详情时的计算快照，便于追溯。模拟入口预检当前数据、所选规模、各交易所模拟余额及已配置的入场费；资金不足时可直接前往设置。市场估计仍使用公开费用假设，最终提交会重新检查。模拟按钮可用不代表真实账户可以下单。

## 模拟模型

- 三类带衍生品的公开市场组合可研究模拟：资金费中性、期现基差、跨所资金费。允许显式确认后模拟未达收益门槛的候选；策略仍 DRAFT / UNPROVEN。
- 两腿按同一次当前盘口走单，全部通过才原子记账。任一腿过期、深度不足、数量无效或资金不足，整笔拒绝。此模型不模拟订单延迟、部分成交和腿风险。
- 每腿按全名义金额预留资金，不使用杠杆。配置费率按交易所与 SPOT / PERPETUAL / FUTURE 分开；开仓时冻结该笔模拟费率，退出使用同一费率假设。未配置时采用公共策略费用假设。
- 跨所现货价差需要预置现货库存；当前不具备库存调拨账本，禁止用卖空现货伪造模拟成交。仍可查看公开经济计算。
- 期现基差可以手动触发模拟平仓；合约到期触发提醒，自动交割结算尚未实现。
- 实盘下单路径始终关闭。私人账户费率录入不代表账户权限或风险验收。

## 结算与损益

- 开仓只扣费用并预留本金，不把预期收益记账。
- 现货价差损益按基础币数量 ×（退出价 × 退出美元汇率 − 入场价 × 入场美元汇率）计算。
- 线性衍生品价差损益按方向 × 基础币数量 ×（退出价 − 入场价）× 退出美元汇率计算。
- 模拟资金费取交易所已结算费率，用结算前后 120 秒内采集的标记价及观测美元参考价估算；结果明确标记为模拟估计，不是假装真实到账。只处理开仓之后、平仓之前的结算，按腿和结算时刻去重，重启不重复入账。
- 没有相邻结算价格、历史覆盖不足或数据过期时提示待核对；不拿今天价格或预测费率填补。跨越长时间离线的数据不能自动视为完整。
- 手动账本资金费以本人填入的实际美元收付额入账，收正付负。额外费用单独录入。不同请求不能用相同交易所流水编号重复计费。
- 净值 = 可用账面现金 + 占用本金 + 未实现损益。总损益 = 已实现价差 + 资金费 − 费用 + 未实现损益。入金/出金不计收益。
- 现金按手动 USD 账面值计量，不自动重估稳定币现金汇兑；持仓未实现损益使用新鲜退出侧盘口及公开美元参考价，不含未来退出手续费。缺估值时净值为空，不填零。
- 账本恒等式差额为零只证明内部计算一致，不证明交易所对账或经济验证。手动绩效为本人记录，PAPER 绩效为模拟，均不产生已验证 Alpha。

## 持仓提示

止损/止盈（USD）、最长持有时间（小时）由本人填写，0 表示关闭。今日展示最多三条关注事项，持仓显示全部原因，包括资金费支付、跨所净资金费转负、交割临近、对冲偏差、估值缺失和结算证据不足。仅页面提醒，不自动退出；桌面通知仍后置。

## API

所有 POST 需 `X-Alpha-Client: owner-ui`、JSON 和唯一 `requestId`，同请求重试幂等，不同内容或操作重用编号会拒绝。

| 路径 | 方法 | 用途 |
| --- | --- | --- |
| /api/personal?mode=PAPER 或 MANUAL | GET | 个人账本、持仓、账户、绩效与流水 |
| /api/personal/flows | POST | mode、venue、type=DEPOSIT/WITHDRAWAL、amountUsd、note |
| /api/personal/fees | POST | mode、venue、kind=SPOT/PERPETUAL/FUTURE、takerBps |
| /api/personal/open | POST | PAPER: candidateId、sizeUsd、acknowledgeResearch；MANUAL: at、title、legs；可附提醒阈值 |
| /api/personal/positions/:id/close | POST | PAPER 按新盘口模拟；MANUAL 提交 at 及各腿 fills 的 legId、price、quoteUsd、feeUsd |
| /api/personal/positions/:id/cashflows | POST | MANUAL: legId、type=FUNDING/FEE、amountUsd、at、reference |
| /api/personal/positions/:id/risk | POST | stopLossUsd、takeProfitUsd、maxHoldHours |
| /api/personal/sync | POST | 使用已采集公开数据检查结算和记录净值，无需 requestId |
| /api/export?workspace=personal | GET | 同一 v1.0.7 分析格式，个人账本视图 |

手动 legs 字段：instrumentId、side=BUY/SELL、quantity（基础币）、price、quoteUsd、feeUsd、collateralUsd（衍生品）。当前工具列表来自公开发现，未支持任意历史已退市工具。记录输入是账本数据，不是发送给交易所的订单。

默认存储 `.data/personal-books.json`；原模拟示例账本保留，并通过“查看旧版示例演练”访问。新增记录采用原子文件写入；生产存储与备份不在本批范围。

净值曲线记录的是运行期间按当时已录入数据采样的结果；后来补录历史成交不会重写旧采样，不把该采样序列当作完整历史净值或 TWR。
