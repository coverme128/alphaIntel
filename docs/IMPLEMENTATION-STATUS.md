## 本批个人用途范围

已实现前四项的基础使用流程，完整口径及限制见 PERSONAL-USE.md。手动账本来源为 OWNER_REPORTED，模拟账本为 PAPER；二者不能合并为真实收益。净值是 USD 账面现金及公开参考持仓估值，不是经过交易所对账和估值审批的 NAV。生产基础设施后置，无需等待密钥才能使用本批功能。

个人流程浏览器验收：在独立 `/tmp/alpha-personal-ui-check` 数据目录完成真实盘口双腿模拟开仓/平仓和阈值提醒，以及手动本金、永续成交、资金费和平仓录入。手动测试案例价差 10 USD、资金费 0.2 USD、费用 1 USD，净损益 9.2 USD；两本账恒等式差额均为 0。个人导出 HTTP 200，不含固定示例机会。测试资金未写入默认个人账本。
