# 界面截图

采集时间：2026-11-19，Asia/Shanghai。来自当前源码构建的真实页面，没有修改收益、机会数量或连接状态。

| 文件 | 内容 |
| --- | --- |
| `opportunities.jpg` | 默认机会总览：当前结论、分组和有效数据状态 |
| `candidates.jpg` | 跨所资金费候选列表：本金、模型净收益、周期与未达门槛原因 |
| `candidate-detail.jpg` | 单个候选详情：费用估计与零模拟余额下的操作限制 |

使用独立临时 `ALPHA_DATA_DIR`，不加载个人账本；公开行情随拍摄时刻变化。零模拟资金不是真实账户余额。截图中候选可能处于负收益或待更新状态，这是如实展示，不构成收益承诺。图片仅包含应用页面，不包含终端、浏览器账号栏或密钥。

重拍时先构建，再启动独立实例，例如：

```sh
npm run build
ALPHA_DATA_DIR=$(mktemp -d) ALPHA_PUBLIC_AUTOSTART=true PORT=4318 npm start
```

打开 `http://127.0.0.1:4318/#Opportunities`，等待真实公开数据加载，使用页面按钮查看列表和详情。拍摄后人工检查是否出现私人数据，更新图片与本说明的日期；停止临时实例。不要把临时数据目录提交到 Git。
